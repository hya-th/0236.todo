# 메이플스토리 월드(MSW) 인게임 설정 UI 제작 요청 프롬프트

플레이 중 일시정지로 진입하는 모바일 세로형 설정 팝업. 앞서 만든 전체 설정 창(탭 + 키 전환 + 적용 버튼)과는 다른 화면이다.

## 앞 화면과 달라지는 점 (설계 전 확인)

| 항목 | 전체 설정 창 | **이 인게임 팝업** |
|---|---|---|
| 진입 | 메뉴 | 플레이 중 상단 일시정지 버튼 |
| 게임 상태 | 정지 불필요 | **열리는 동안 게임 일시정지** |
| 확정 방식 | "적용" 눌러야 저장 | **적용 버튼 없음 → 조작 즉시 반영·즉시 저장** |
| 항목 | 사운드 + 키 전환 | 사운드만 |
| 추가 동작 | — | 홈으로 돌아가기 / 스테이지 재도전 |
| 화면 | 가로 2단 | 모바일 세로 1단 |

## A. 전체 버전 (권장)

메이플스토리 월드(MapleStory Worlds)에서 **플레이 중 접근하는 인게임 설정 팝업**을 만들어줘.
UI는 Maker의 UI 편집기로 구성하고, 동작 로직은 Lua로 작성해줘. 모바일 세로 화면 기준이야.

### 1. 진입과 게임 일시정지

- 상단 HUD 우측의 **일시정지(⏸) 버튼**을 누르면 이 팝업이 열려. 모바일 뒤로가기 / ESC로도 열리게 해줘.
- 팝업이 열리는 순간 **게임을 일시정지**해줘.
  - 캐릭터·몬스터 이동과 애니메이션, 스테이지 타이머, 투사체·물리 연산 정지.
  - 조이스틱, 공격·점프 버튼 등 플레이 입력 차단(팝업 뒤쪽 터치가 게임에 전달되지 않아야 함).
  - 배경 음악은 계속 재생하되 볼륨 조절이 들려야 하고, 진행 중이던 효과음은 정지.
- 팝업을 닫으면 정지 직전 상태 그대로 재개해줘. 재개 시 3·2·1 카운트다운을 넣을지는 제안해주고, 기본은 즉시 재개로 해줘.
- 이미 열려 있으면 중복으로 열리지 않게 하고, 열려 있는 동안 일시정지 버튼은 비활성화해줘.

### 2. 레이아웃 (모바일 세로, 1080×1920 기준)

- **딤 배경**: 화면 전체, 검정 40% 투명도. 딤을 눌러도 닫히지 않게 해줘(오조작 방지).
- **팝업 카드**: 가로는 화면 폭의 약 70%, 세로는 내용에 맞춰 자동, 화면 정중앙 정렬. 흰색 배경, 라운드 24px, 부드러운 그림자. 노치·홈 인디케이터 안전영역을 침범하지 않게 해줘.
- **헤더**: 좌측에 톱니바퀴 아이콘 + "설정"(30pt, 볼드, 진한 남색), 우측에 X 닫기 버튼(터치 영역 최소 88×88px).
- **사운드 섹션**
  - 섹션 라벨: 스피커 아이콘 + "사운드 설정"(20pt, 회청색).
  - 슬라이더 행 3개(행 높이 72px): ♪ 배경 음악 70%, 🔊 효과음 80%, 🎤 음성 60%.
  - 행 구성: [아이콘 36px] [라벨 130px] [슬라이더 가변폭] [퍼센트 70px, 우측 정렬].
  - 슬라이더: 트랙 높이 10px 라운드, 채워진 구간 파란색 / 빈 구간 연회색, 핸들은 지름 30px 흰 원 + 파란 테두리 + 옅은 그림자.
- **구분선**: 사운드 섹션과 버튼 영역 사이 옅은 회색 1px.
- **버튼 영역**: 세로 스택, 카드 좌우 패딩까지 꽉 채운 폭, 높이 76px, 라운드 14px, 간격 14px.
  1. 🏠 **홈 화면으로 돌아가기** — 흰 배경 + 옅은 파란 테두리, 아이콘 파랑 + 텍스트 남색
  2. ↻ **스테이지 재도전** — 위와 동일 스타일
  3. **닫기** — 연한 파란 배경 채움, 테두리 없음, 텍스트 남색, 아이콘 없음
- 팝업이 열릴 때 페이드 인 + 살짝 확대되는 짧은 연출(0.15초)을 넣어줘.

| "닫기" 버튼 배경 | `#E8F1FB` |

| 딤 배경 | `#000000` 40% |

### 4. 사운드 기능

- 배경 음악 / 효과음 / 음성을 **독립된 3채널**로 관리하고 각 채널 볼륨을 설정값에서 가져와줘.
- 값은 0~100 정수로 스냅되고, 드래그하는 동안 우측 퍼센트 텍스트가 실시간 갱신돼야 해. 내부적으로 0.0~1.0으로 변환해서 실제 볼륨에 반영하고 **0%는 완전 무음**이어야 해.
- **이 화면에는 "적용" 버튼이 없으니 값이 바뀌는 즉시 실제 볼륨에 반영하고 곧바로 저장해줘.** 드래그 중에 매 프레임 저장하지 말고, 슬라이더를 놓는 시점에 한 번만 저장(디바운스)해줘.
- 효과음·음성은 슬라이더를 놓는 순간 샘플 사운드를 1회 재생해서 크기를 확인할 수 있게 해줘.
- 게임 안의 모든 사운드 재생이 이 채널 볼륨을 거치도록 재생 호출을 공통 함수로 정리해줘.
- 저장은 `PlayerData`에 `{ version = 1, volume = { bgm = 70, sfx = 80, voice = 60 } }` 형태로 하고, 플레이어 입장 시 불러와 반영해줘. 저장값이 없거나 깨졌으면 기본값(70/80/60)으로 폴백해줘.

### 5. 버튼 동작

- **홈 화면으로 돌아가기**
  - "진행 중인 스테이지가 초기화됩니다. 홈으로 나갈까요?" 확인 팝업을 먼저 띄워줘.
  - 확인 시 일시정지 해제 → 스테이지 상태·타이머·스폰된 오브젝트 정리 → 홈(로비) 맵으로 이동.
  - 획득한 코인·보석 등 재화를 스테이지 중도 이탈 시 유지할지 버릴지 정책을 물어봐줘. 기본은 **중도 이탈 시 미획득 처리**로 해줘.
- **스테이지 재도전**
  - "현재 스테이지를 처음부터 다시 시작할까요?" 확인 팝업을 먼저 띄워줘.
  - 확인 시 현재 스테이지를 시작 시점 상태로 리셋해줘: 캐릭터 위치·체력(하트 3), 몬스터·아이템 재배치, 스테이지 타이머, 이번 판에서 먹은 코인·보석 회수.
  - 리셋이 끝나면 팝업을 닫고 게임을 재개해줘.
- **닫기 / X**: 팝업을 닫고 게임을 즉시 재개해줘. 두 버튼 동작은 동일해.
- 홈·재도전은 되돌릴 수 없으니 **연타로 두 번 실행되지 않게** 처리하고, 처리 중에는 버튼을 비활성화해줘.

### 6. 산출물 요구사항

- 스크립트를 역할별로 나눠줘: 일시정지 제어(`PauseManager`), 설정 상태·저장(`SettingsManager`), 사운드 채널(`SoundManager`), 팝업 UI 바인딩.
- UI 엔티티 계층 구조(부모-자식 트리)와 각 노드의 앵커·피벗·크기 값을 먼저 설명해주고 진행해줘.
- 앵커와 피벗으로 다양한 세로 해상도와 화면 비율에서 중앙 정렬·비율이 유지되게 해줘. 모든 터치 타깃은 최소 88×88px을 확보해줘.
- 작업 전에 프로젝트의 기존 사운드 재생 코드, 스테이지 진행·리셋 코드, `PlayerData` 저장 코드를 확인하고 수정 대상 파일을 알려준 다음 진행해줘.
- 구현 후 아래를 직접 확인해서 결과를 알려줘.
  1. 팝업이 열린 동안 캐릭터·몬스터가 완전히 멈추고, 뒤쪽 조작 버튼이 눌리지 않는지
  2. 볼륨을 바꾸고 재접속해도 값이 유지되는지
  3. 재도전 후 체력·코인·몬스터가 스테이지 시작 상태로 돌아오는지
  4. 홈으로 나간 뒤 다시 스테이지에 들어가도 이전 판의 상태가 남지 않는지
- MSW API 이름은 추측하지 말고 실제 지원되는 것으로 확인해서 쓰고, 지원되지 않아 대체 구현이 필요하면 임의로 진행하지 말고 먼저 알려줘.

## B. 짧은 버전

메이플스토리 월드에서 **플레이 중 일시정지 버튼으로 여는 인게임 설정 팝업**을 모바일 세로 화면 기준으로 만들어줘. 흰 카드 + 파란 포인트 톤이야.

- **구성**: 헤더(톱니바퀴 + "설정", 우측 X) / 사운드 섹션(배경 음악 70%, 효과음 80%, 음성 60% 슬라이더 3개) / 구분선 / 세로로 쌓인 버튼 3개 — "🏠 홈 화면으로 돌아가기", "↻ 스테이지 재도전", "닫기"(연파랑 채움).
- **일시정지 연동**: 팝업이 열리면 캐릭터·몬스터·타이머·물리를 멈추고 조이스틱과 공격·점프 버튼 입력을 차단해줘. 닫으면 정지 직전 상태로 재개. 딤 배경을 눌러도 닫히지 않게 해줘.
- **사운드**: 3채널을 분리해 0~100 값을 실제 볼륨(0.0~1.0)에 반영하고 0%는 완전 무음. **적용 버튼이 없으니 즉시 반영하고, 슬라이더를 놓는 시점에 `PlayerData`에 저장**해줘. 효과음·음성은 놓을 때 샘플 사운드 1회 재생.
- **홈으로 돌아가기 / 스테이지 재도전**: 각각 확인 팝업을 먼저 띄우고, 홈은 스테이지 상태를 정리한 뒤 로비로, 재도전은 체력·몬스터·아이템·타이머·획득 재화를 스테이지 시작 상태로 리셋한 뒤 팝업을 닫고 재개해줘. 둘 다 연타로 두 번 실행되지 않게 막아줘.
- 다양한 세로 해상도에서 중앙 정렬이 유지되게 앵커·피벗을 잡고, 터치 타깃은 최소 88×88px을 확보해줘.

UI 엔티티 계층 구조를 먼저 설명해주고, 기존 사운드·스테이지 리셋·`PlayerData` 코드를 확인한 뒤 수정 대상 파일을 알려주고 진행해줘.
