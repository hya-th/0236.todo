# 메이플스토리 월드(MSW) 설정 UI 제작 요청 프롬프트

아래 내용을 그대로 복사해서 사용하면 됩니다. 첨부 이미지(설정 창 스크린샷)를 함께 첨부하는 것을 권장합니다.

---

## 전체 버전 (권장)

메이플스토리 월드(MapleStory Worlds)에서 아래 명세대로 **인게임 설정(Settings) 팝업 UI**를 제작해줘.
UI는 Maker의 UI 편집기로 구성하고, 동작 로직은 Lua 스크립트로 작성해줘.

### 1. 화면 개요

게임 화면 위에 반투명 딤(dim) 처리된 배경과 함께 뜨는 **모달 팝업**이야.
왼쪽은 카테고리 탭 네비게이션, 오른쪽은 선택된 카테고리의 상세 설정을 보여주는 2단 레이아웃이고,
오른쪽 하단에 "기본값 복원 / 적용" 버튼이 있어.

### 2. 레이아웃 명세 (1920×1080 기준, 비율 유지)

- **딤 배경**: 화면 전체, 검정 30% 투명도. 딤 영역 클릭 시에는 닫히지 않음(오작동 방지).
- **팝업 패널**: 가로 1000px, 세로 980px, 화면 정중앙 정렬, 모서리 라운드 24px, 은은한 그림자.
- **닫기(X) 버튼**: 팝업 우측 상단 모서리에 걸치도록 배치, 지름 56px 원형 버튼.
- **좌측 사이드바**: 폭 320px, 팝업과 같은 높이, 좌측 모서리만 라운드.
  - 상단: 톱니바퀴 아이콘 + "설정" 타이틀 (28pt, 볼드).
  - 탭 목록(세로 스택, 항목 높이 72px, 간격 12px):
    1. 🔊 "사운드 설정"
    2. ⌨ "키 전환"
  - 선택된 탭은 밝은 초록 배경 + 라운드 16px로 하이라이트, 비선택 탭은 배경 없음.
  - 사이드바 최하단: "저장된 설정은 PlayerData에 저장됩니다." 안내 문구 (16pt, 초록 계열, 2줄 줄바꿈 허용).
- **우측 콘텐츠 영역**: 폭 680px, 내부 패딩 32px, 세로 스크롤 지원.

#### 2-1. 사운드 설정 섹션

- 섹션 헤더: 스피커 아이콘 + "사운드 설정" (24pt, 볼드).
- 슬라이더 행 3개 (행 높이 64px):
  | 아이콘 | 라벨 | 기본값 |
  |---|---|---|
  | ♪ | 배경 음악 | 70% |
  | 🔊 | 효과음 | 80% |
  | 🎤 | 음성 | 60% |
- 각 행 구성: [아이콘 40px] [라벨 120px] [슬라이더 가변폭] [퍼센트 텍스트 80px, 우측 정렬].
- 슬라이더: 트랙 높이 10px 라운드, 채워진 구간은 진한 초록 / 빈 구간은 연한 회녹색, 핸들은 지름 28px 흰색 원 + 초록 테두리.
- 값은 0~100 정수 단위로 이동하며, 드래그 중 실시간으로 퍼센트 텍스트가 갱신돼야 함.

#### 2-2. 구분선

사운드 섹션과 키 전환 섹션 사이에 옅은 회색 가로 구분선 1px.

#### 2-3. 키 전환 섹션

- 섹션 헤더: 키보드 아이콘 + "키 전환" (24pt, 볼드).
- 서브 텍스트: "키 설정을 변경할 수 있습니다." (16pt, 연한 회색).
- 스크롤 가능한 키 바인딩 리스트 (한 번에 5행 노출, 우측에 라운드 스크롤바 표시):
  | 액션 | 기본 키 |
  |---|---|
  | 이동 - 좌 | A |
  | 이동 - 우 | D |
  | 점프 | Space |
  | 공격 | J |
  | 대시 | K |
- 각 행: 높이 56px, 행 간격 12px, 연한 초록 배경 + 라운드 12px.
  좌측에 액션 이름, 우측에 현재 키가 적힌 흰색 키 버튼(폭 130px, 높이 40px, 라운드 8px, 옅은 테두리).

#### 2-4. 하단 버튼 영역

- 우측 하단 정렬, 버튼 2개 (높이 60px, 라운드 12px, 간격 16px):
  - **기본값 복원**: 아웃라인 스타일(배경 없음 또는 아주 연한 배경 + 회녹색 테두리), 폭 200px.
  - **적용**: 진한 초록 채움 + 흰색 텍스트, 폭 230px.

### 3. 컬러 팔레트

전체적으로 자연스러운 크림 + 세이지 그린 톤을 사용해줘.

| 용도 | HEX |
|---|---|
| 팝업 본문 배경 | `#F7F8F1` |
| 좌측 사이드바 배경 | `#E9ECDD` |
| 선택된 탭 배경 | `#D6E3CC` |
| 리스트 행 배경 | `#E9EFE2` |
| 기본 텍스트 | `#4A5A46` |
| 보조/설명 텍스트 | `#8A9686` |
| 포인트 그린(적용 버튼, 슬라이더 채움) | `#6C9A6E` |
| 슬라이더 빈 트랙 | `#DCE5D5` |
| 키 버튼 배경 / 테두리 | `#FFFFFF` / `#C9D6BF` |
| 닫기 버튼 원형 배경 | `#4F6B4B` (아이콘은 흰색) |

### 4. 동작 명세

1. **탭 전환**: 좌측 탭 클릭 시 우측 콘텐츠가 해당 섹션으로 스크롤 이동하거나 해당 섹션만 노출되도록 처리하고, 선택된 탭 하이라이트를 갱신해줘.
2. **슬라이더**: 드래그/클릭으로 값 변경. 값이 바뀌면 즉시 실제 볼륨에 반영(배경 음악 / 효과음 / 음성 각각 분리된 볼륨 채널).
3. **키 재설정**: 키 버튼을 클릭하면 버튼이 "입력 대기" 상태(텍스트를 `...`로 바꾸고 강조 테두리)로 바뀌고, 다음에 누르는 키를 해당 액션에 할당해줘.
   - 이미 다른 액션에 할당된 키를 누르면 "이미 사용 중인 키입니다" 토스트/문구를 띄우고 변경을 취소해줘.
   - ESC를 누르면 재설정을 취소하고 원래 키로 되돌려줘.
4. **적용**: 현재 화면의 값들을 `PlayerData`(또는 프로젝트에서 사용하는 저장 컴포넌트)에 저장하고 팝업을 닫아줘.
5. **기본값 복원**: 위 표의 기본값(70/80/60, A·D·Space·J·K)으로 UI를 되돌려줘. 이때 저장은 "적용"을 눌러야 확정되도록 해줘.
6. **닫기(X)**: 저장하지 않고 팝업을 닫아줘. 변경사항이 있으면 확인 팝업을 띄우거나 마지막 저장값으로 되돌려줘.
7. **초기화**: 팝업이 열릴 때 `PlayerData`에 저장된 값을 불러와서 UI에 반영하고, 저장된 값이 없으면 기본값을 사용해줘.

### 5. 산출물 요구사항

- UI 엔티티 계층 구조(부모-자식 트리)를 먼저 설명해주고, 각 노드의 앵커/피벗/크기 설정값을 함께 알려줘.
- 반응형: 앵커와 피벗을 활용해서 해상도가 달라져도 팝업이 화면 중앙에 유지되고 비율이 깨지지 않게 해줘.
- Lua 스크립트는 UI 컴포넌트 스크립트로 붙일 수 있는 형태로, 함수 단위로 나눠서 작성하고 주석을 달아줘.
- 모바일 터치 입력에서도 슬라이더 드래그와 버튼 탭이 동작하도록 고려해줘.
- MSW에서 지원하지 않는 기능이나 대체 구현이 필요한 부분이 있으면 임의로 진행하지 말고 먼저 알려줘.

## 짧은 버전

메이플스토리 월드에서 인게임 **설정 팝업 UI**를 만들어줘. 크림 + 세이지 그린 톤의 모달이고,
왼쪽에 "사운드 설정 / 키 전환" 탭 사이드바, 오른쪽에 상세 설정이 들어가는 2단 레이아웃이야.

- **사운드 설정**: 배경 음악(70%), 효과음(80%), 음성(60%) 슬라이더 3개. 드래그하면 퍼센트 텍스트와 실제 볼륨이 실시간 반영돼야 해.
- **키 전환**: 이동-좌(A), 이동-우(D), 점프(Space), 공격(J), 대시(K) 5개 항목의 스크롤 리스트. 키 버튼을 누르면 입력 대기 상태가 되고 다음에 누른 키로 바뀌되, 중복 키는 거부해줘.
- **하단 버튼**: "기본값 복원"(아웃라인) / "적용"(진한 초록 채움). 적용을 누르면 `PlayerData`에 저장되고 팝업이 닫혀. 우측 상단에는 원형 닫기(X) 버튼.
- 팝업이 열릴 때 `PlayerData`에 저장된 값을 불러와 UI에 반영하고, 없으면 기본값을 써줘.

UI 엔티티 계층 구조와 Lua 스크립트를 함께 작성해주고, 해상도가 바뀌어도 중앙 정렬이 유지되게 앵커/피벗을 설정해줘.
