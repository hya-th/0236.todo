## B. 구현 요청 프롬프트 (그대로 복사해서 사용)

메이플스토리 월드(MapleStory Worlds)에서 이미 만들어 둔 **인게임 설정 팝업에 실제 동작을 붙여줘.**
레이아웃과 디자인은 완성돼 있고, 지금 필요한 건 기능 로직이야. Lua로 구현해줘. 모바일 세로 화면 기준이야.

작업 전에 프로젝트의 **스테이지 진행·리셋 코드, 캐릭터 입력 처리 코드, 사운드 재생 코드, 재화(코인·보석) 처리 코드, `PlayerData` 저장 코드**를 먼저 확인하고, 수정할 파일 목록을 알려준 다음 진행해줘. MSW API 이름은 추측하지 말고 실제 지원되는 것으로 확인해서 써줘.

### 1. 일시정지 시스템 (가장 먼저)

- 게임 전체의 정지/재개를 관리하는 `PauseManager`를 만들어줘. 팝업이 아니라 이 매니저가 정지의 주체여야 하고, 나중에 다른 팝업도 같은 방식으로 정지를 걸 수 있게 해줘.
- **정지 대상**: 캐릭터·몬스터의 이동과 애니메이션, 몬스터 AI, 스포너, 투사체, 물리 연산, 스테이지 타이머, 버프·스킬 쿨타임, 진행 중인 트윈·연출.
- **정지 중 시간이 누적되면 안 돼.** 스테이지 타이머와 쿨타임은 정지 시간을 빼고 계산되게 해줘.
- **재개 시 delta 튐 방지**: 재개 첫 프레임에 정지 기간만큼의 큰 delta가 들어가 캐릭터가 순간이동하지 않도록 처리해줘.
- **상태 복원**: 정지 직전의 이동 방향·속도·애니메이션 진행 상태를 그대로 이어서 재개해줘.
- **입력 차단**: 정지 중에는 가상 조이스틱과 공격·점프 버튼 입력이 캐릭터에 전달되지 않아야 해. 팝업 뒤쪽 영역을 터치해도 게임 조작이 되지 않도록 딤 배경이 터치를 가로채게 해줘(터치 관통 차단).
- **진입점**: 상단 HUD의 일시정지(⏸) 버튼, 그리고 모바일 뒤로가기 / ESC. 이미 열려 있으면 중복으로 열리지 않게 하고, 열려 있는 동안 일시정지 버튼은 비활성화해줘.
- 앱이 백그라운드로 내려갔다 돌아올 때 자동으로 일시정지를 걸지 여부를 제안해줘. 지원 가능하면 **자동 일시정지**를 기본으로 해줘.
- 이 게임이 멀티플레이라 월드를 멈출 수 없는 구조라면, 임의로 진행하지 말고 "정지 없이 열기 + 입력만 차단" 방식으로 갈지 먼저 물어봐줘.

### 2. 사운드 기능

- 배경 음악 / 효과음 / 음성을 독립된 3채널로 관리하고 각 채널 볼륨을 설정값에서 가져와줘.
- 슬라이더 값은 0~100 정수로 스냅되고 드래그 중 퍼센트 텍스트가 실시간 갱신돼야 해. 내부적으로 0.0~1.0으로 변환해 실제 볼륨에 반영하고 **0%는 완전 무음**이어야 해.
- **이 화면에는 "적용" 버튼이 없어.** 값이 바뀌는 즉시 실제 볼륨에 반영하고 곧바로 저장하되, 드래그 중 매 프레임 저장하지 말고 **슬라이더를 놓는 시점에 한 번만 저장(디바운스)** 해줘.
- 효과음·음성은 슬라이더를 놓는 순간 샘플 사운드를 1회 재생해서 크기를 확인할 수 있게 해줘.
- 일시정지 중에도 배경 음악은 계속 재생해서 볼륨 조절이 들리게 하고, 진행 중이던 효과음은 정지했다가 재개 시 정상 복구해줘.
- 게임 안의 모든 사운드 재생이 이 채널 볼륨을 거치도록 재생 호출을 공통 함수로 정리해줘.
- 저장은 `PlayerData`에 `{ version = 1, volume = { bgm = 70, sfx = 80, voice = 60 } }` 형태로 하고, 플레이어 입장 시 불러와 게임 전체에 반영해줘. 값이 없거나 형식이 깨졌으면 기본값(70/80/60)으로 폴백하고, 나중에 항목이 추가돼도 저장값과 기본값을 병합해서 누락분만 채우게 해줘.

### 3. 홈 화면으로 돌아가기

- "진행 중인 스테이지가 초기화됩니다. 홈으로 나갈까요?" 확인 다이얼로그를 먼저 띄우고, 확인했을 때만 실행해줘.
- 실행 순서를 지켜줘: **일시정지 해제 → 스테이지 정리 → 홈(로비) 이동**. 정지 상태로 씬을 옮기면 로비까지 멈춘 채로 넘어가니 반드시 해제를 먼저 해줘.
- 스테이지 정리에서 스폰된 몬스터·아이템·투사체 엔티티, 등록한 이벤트 핸들러, 실행 중인 코루틴·타이머를 모두 해제해서 누수가 남지 않게 해줘.
- 이번 판에서 획득한 코인·보석을 유지할지 버릴지는 정책을 물어봐주고, 기본은 **중도 이탈 시 미획득 처리**로 구현해줘.
- 처리 중에는 버튼을 비활성화하고 로딩 표시를 띄워서 연타로 두 번 실행되지 않게 막아줘.

### 4. 스테이지 재도전

- "현재 스테이지를 처음부터 다시 시작할까요?" 확인 다이얼로그를 먼저 띄우고, 확인했을 때만 실행해줘.
- **스테이지 시작 시점의 상태를 스냅샷으로 저장해 두거나, 리셋 절차를 명시적으로 정의**해서 재도전 시 그 상태로 되돌려줘. 리셋 범위는 이렇게 해줘.
  - 캐릭터 위치·상태·체력(하트 3), 진행 중이던 버프·쿨타임 초기화
  - 몬스터·아이템·기믹 재배치, 남아 있는 투사체와 이펙트 제거
  - 스테이지 타이머 초기화, 카메라를 시작 위치로 복귀
  - **이번 판에서 획득한 코인·보석만 롤백** — HUD에 보이는 값이 누적 보유량이라면 전체를 0으로 만들지 말고 이번 판 증가분만 되돌려줘. 이를 위해 스테이지 진입 시점의 보유량을 따로 기록해줘.
- 처음부터 시작할지 마지막 체크포인트부터 시작할지는 결정이 필요하니 물어봐줘. 체크포인트 시스템이 없으면 처음부터로 해줘.
- 리셋이 끝나면 **팝업 닫기 → 일시정지 해제** 순서로 재개해줘. 여기서도 연타 방지를 적용해줘.

### 5. 창 흐름

- **닫기 / X**: 둘 다 동일하게 팝업을 닫고 즉시 게임을 재개해줘.
- **딤 배경 터치**: 닫히지 않게 무시해줘.
- 재개할 때 3·2·1 카운트다운을 넣을지 제안해주고, 기본은 즉시 재개로 해줘.
- 홈·재도전의 확인 다이얼로그는 **공통 컴포넌트 하나로 만들어서 재사용**해줘(제목·본문·확인/취소 콜백을 받는 형태).
- 모든 터치 타깃은 최소 88×88px을 확보해줘.

### 6. 산출물 요구사항

- 스크립트를 역할별로 나눠줘: `PauseManager`(정지/재개), `SettingsManager`(설정 상태·저장), `SoundManager`(채널 볼륨), `StageController`(리셋·정리·씬 이동), 팝업 UI 바인딩, 공통 확인 다이얼로그.
- 각 함수에 주석을 달고, 어떤 엔티티/컴포넌트에 붙이는 스크립트인지 명시해줘.
- 아래 항목은 직접 확인해서 결과를 알려줘.
  1. 팝업이 열린 동안 캐릭터·몬스터가 완전히 멈추고, 팝업 뒤 조작 버튼이 눌리지 않는지
  2. 30초쯤 열어 뒀다가 닫았을 때 스테이지 타이머가 그만큼 줄지 않았고 캐릭터가 순간이동하지 않는지
  3. 볼륨을 바꾸고 재접속해도 값이 유지되는지, 0%에서 완전히 무음인지
  4. 재도전 후 체력·몬스터·타이머가 시작 상태로 돌아오고, 코인·보석은 이번 판 획득분만 되돌아가는지
  5. 홈으로 나간 뒤 다시 스테이지에 들어갔을 때 이전 판의 엔티티나 타이머가 남아 있지 않은지
- **결정이 필요한 항목**(중도 이탈 시 재화 처리, 체크포인트 정책, 앱 백그라운드 자동 정지, 멀티플레이 여부)은 임의로 진행하지 말고 먼저 물어봐줘. MSW에서 지원되지 않아 대체 구현이 필요한 부분도 마찬가지야.

## C. 짧은 버전

메이플스토리 월드에서 이미 만들어 둔 **인게임 설정 팝업(일시정지 창)** 에 동작 로직을 붙여줘. 디자인은 완성돼 있고 기능만 없어.

1. **일시정지 시스템**: `PauseManager`를 만들어서 팝업이 열리면 캐릭터·몬스터·AI·스포너·투사체·물리·스테이지 타이머·쿨타임·트윈을 모두 멈춰줘. 정지 중 시간이 타이머에 누적되면 안 되고, 재개 첫 프레임에 큰 delta가 들어가 캐릭터가 순간이동하지 않게 처리해줘. 조이스틱과 공격·점프 입력을 차단하고, 팝업 뒤쪽 터치가 게임에 전달되지 않게 딤이 터치를 가로채게 해줘. 진입점은 HUD 일시정지 버튼과 뒤로가기/ESC이고 중복 오픈은 막아줘.
2. **사운드**: 3채널(배경 음악·효과음·음성)을 분리해 0~100 값을 실제 볼륨(0.0~1.0)에 반영하고 0%는 완전 무음. **적용 버튼이 없으니 즉시 반영하되, 슬라이더를 놓는 시점에만 `PlayerData`에 저장(디바운스)** 해줘. 효과음·음성은 놓을 때 샘플 1회 재생, 정지 중에도 BGM은 계속 재생해줘.
3. **홈으로 돌아가기**: 확인 다이얼로그 → **일시정지 해제 → 스테이지 정리(스폰 엔티티·이벤트 핸들러·타이머 해제) → 로비 이동** 순서로 처리해줘. 정지 상태로 씬을 옮기면 로비까지 멈추니 해제를 먼저 해줘. 이번 판 획득 재화 처리 정책은 물어봐주고 기본은 미획득 처리로 해줘.
4. **스테이지 재도전**: 확인 다이얼로그 후 캐릭터 위치·체력(하트 3)·버프, 몬스터·아이템 배치, 타이머, 카메라, 남은 투사체를 시작 상태로 리셋하고, **코인·보석은 이번 판 획득분만 롤백**해줘(HUD 값이 누적 보유량이면 전체 초기화 금지 — 스테이지 진입 시점 보유량을 따로 기록해둬). 리셋 후 팝업 닫고 정지 해제.
5. **공통**: 닫기와 X는 동일 동작(닫고 재개), 딤 터치는 무시, 홈·재도전 확인창은 공통 컴포넌트로 재사용, 되돌릴 수 없는 동작은 처리 중 버튼 비활성화로 연타를 막아줘.

작업 전에 스테이지 리셋·입력·사운드·재화·`PlayerData` 코드를 확인하고 수정 대상 파일을 알려줘. 구현 후에는 정지 중 완전 정지·타이머 미누적·볼륨 영속·재도전 리셋 범위·홈 이탈 후 잔여 상태 없음을 직접 확인해서 알려줘. 재화 정책, 체크포인트 여부, 앱 백그라운드 자동 정지는 임의로 정하지 말고 물어봐줘.
